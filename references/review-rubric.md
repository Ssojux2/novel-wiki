# 장 리뷰 기준

howells/fiction chapter-reviewer의 6축(일관성, 유치함, 연속성, 속도, 톤, 인물 목소리)에 author-toolkit의 편집 페르소나(발전 편집, 라인 편집, 인물 컨설턴트, 연속성 추적)를 겹쳐 만들었다.

## 축
| 축 | 질문 | 페르소나 |
|---|---|---|
| 목적 | 이 장은 아웃라인의 목적을 달성했나? 끝에서 누가 달라졌나? | 발전 편집 |
| 장면 경제 | 각 장면이 두 가지 이상의 일을 하나? 빼도 되는 장면은? | 발전 편집 |
| 속도 | 늘어지는 구간은? 서두른 구간은? 장면과 요약을 제대로 골랐나? | 발전 편집 |
| 긴장·훅 | 첫 문단이 붙잡나? 마지막 문단이 다음 장으로 끌고 가나? | 발전 편집 |
| 유치함 | 과장된 감정, 뻔한 대사, 상투적 반전 | 라인 편집 |
| 문장 | 리듬, 구체성, 보여주기/말하기, 번역투 | 라인 편집 |
| 호흡 | `breath_ko.py` 측정치가 프로필 목표에 맞나? 장면별 모드가 맞게 쓰였나? 장문이 문법적으로 버티나? | 라인 편집 |
| 인물 목소리 | 대사만 읽어도 누가 말하는지 알 수 있나? 바이블의 말투와 맞나? | 인물 컨설턴트 |
| 동기 | 인물의 선택이 원함·필요·상처에서 나오나? 플롯 편의로 움직이나? | 인물 컨설턴트 |
| 연속성 | 맥락 팩·바이블과 충돌하는 것 | 연속성 추적 |
| SF 논리 | 규칙과 기술 한계를 지키나? 정보 덤프는 없나? | 세계관 |

## 연재 축 (주간 연재 회차일 때)
`packs/review-chNN.md`(연재 검토 팩)를 근거로 본다.

| 축 | 질문 |
|---|---|
| 훅 연결 | 지난 화 마지막 장면의 훅을 이번 화가 받았나 (바로 받기, 비틀어 받기, 의도적 지연)? 지연했다면 이번 화 안에 보상이 있나? |
| 재진입 | 일주일 만에 돌아온 독자가 첫 두 문단 안에 '누가, 어디서, 무엇을'을 다시 잡을 수 있나? 요약 문단으로 때우지 않고 장면 안에서 되살렸나? |
| 회차 완결성 | 이번 화에도 작은 아크(문제 → 전환 → 새 국면)가 있나? 다음 화를 기다리게 하는 마지막 훅이 있나? |
| 기억 거리 | 오래 안 나온 인물·장소·복선이 돌아올 때, 독자를 위한 짧은 회상 단서가 있나? 처음 나온 개체는 충분히 소개됐나? |
| 회차 간 반복 | 이전 회차와 같은 묘사·비유·문장 습관을 재사용하지 않았나? 의도한 모티프라면 변주가 있나? |
| 문체 일관성 | 분량, 호흡, 대사 비율이 이전 회차 추세에서 튀지 않나? 튄다면 의도인가? |

연재 축의 지적에는 반드시 근거 회차를 단다 (예: "ch09 마지막 문단의 '문이 열려 있었다'를 받지 않음").

## 출력 형식

```markdown
# chNN 리뷰

## 판정: 다음 장으로 / 수정 후 진행 / 재작성 권장

## 잘 된 것 (인용과 함께 2~4개)
- "…" — 이유

## 고칠 것 (우선순위순)
### 1. [축] 문제 요약
- 위치: L23~31
- 왜: …
- 제안 고쳐쓰기:
  > 원문: …
  > 수정: …

## 연재 (연재 회차일 때)
- [훅 연결] … (근거: ch11 마지막 문단)
- [기억 거리] …

## 연속성 플래그
- L40: … (근거: bible/characters/한서윤.md ch07 행)

## 바이블 반영 필요 (ingest 때 처리)
- 새 설정: …
```

원칙: 칭찬도 구체적으로 한다. 고칠 것은 최대 7개로 추리고, 고쳐쓰기는 작가의 목소리를 유지한다. 리뷰어가 자기 문체로 다시 쓰지 않는다.
