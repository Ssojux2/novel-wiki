# 바이블 스키마와 Ingest 절차

스크립트(`state_at.py`, `context_pack.py`, `lint_bible.py`)가 이 형식을 파싱한다. 형식을 지켜야 자동화가 동작한다.

## 폴더

```
bible/
├── _overview.md   _index.md   _log.md
├── characters/  places/  factions/  tech/     ← 상태를 가진 개체 (상태 변화 표)
├── rules/                                     ← 세계 규칙 (상태 없음)
├── arcs/                                      ← 인물 아크·플롯 라인 종합
├── chapters/chNN.md                           ← 장 요약 (ingest 결과)
├── timeline.md  threads.md  terms.md          ← 대장(ledger)
└── _templates/                                ← 페이지 템플릿
```

파일 이름 = 정식 이름(예: `characters/한서윤.md`). 별칭은 frontmatter `aliases`에 넣는다. 스크립트는 이름과 별칭으로 원고·아웃라인 언급을 찾는다.

## 상태 변화 표 (World Model의 핵심)

`## 상태 변화` 제목 아래 첫 표. 첫 열은 `장`(ch01 형식).

| 규칙 | 예 |
|---|---|
| 장별 **변화분만** 적는다. 빈칸은 이전 값 유지 | `ch07 | | 왼팔 부상 | | |` |
| 일반 열은 새 값으로 **교체** | 위치, 상태, 통제 세력 |
| `앎`·`소지품`은 집합. `+추가`, `-제거`, 쉼표로 여러 개 | `+기지의 비밀, -출입카드` |
| 접두어 없이 쓰면 집합을 통째로 교체 | `손전등, 산소통` |
| `관계`는 `이름: 값` 쌍. 같은 이름은 덮어씀. 값이 `-`면 삭제 | `도윤: 의심, 박소장: 적대` |
| `상태`에 `사망`이 들어가면 이후 장 재등장을 lint가 경고 | `사망 (차폐막 붕괴)` |
| 같은 장에서 여러 번 바뀌면 그 장 끝 상태 하나만 적는다 | |

`앎`은 POV 지식 위반 검사의 근거다. 인물이 정보를 **알게 되는 장**에 정확히 기록한다.

## 대장(ledger)

**timeline.md** `| 장 | 이야기 내 시각 | 구분 | 사건 | 장소 | 관련 인물 |`
- 시각은 `D+일수 HH:MM`. 회상·예지·기록 장면은 `구분`에 `회상`.

**threads.md** `| id | 복선·떡밥 | 심은 장 | 회수 예정 | 회수 장 | 상태 | 비고 |`
- id는 `T01`부터. 상태는 `open` / `paid` / `dropped`.
- 아웃라인 frontmatter의 `threads_plant`, `threads_payoff`와 id로 연결된다.

**terms.md** `| 정본 | 금지 변형 | 분류 | 첫 등장 | 설명 |`
- 금지 변형은 쉼표로 구분. 띄어쓰기 변형도 여기서 금지한다.

## 장 요약 `chapters/chNN.md`

`_templates/chapter.md` 형식. frontmatter의 `ingested` 날짜를 남긴다. lint는 원고가 요약보다 나중에 수정됐으면 재-ingest를 제안한다.

## Ingest 절차 (한 장)

1. 원고 `manuscript/chNN.md`를 끝까지 읽는다. 직전 장 요약과, 이 장에 등장하는 개체 페이지를 읽는다.
2. `chapters/chNN.md` 작성: 요약, 장면 표, 반영한 상태 변화, 심은/회수한 복선, 새 설정, 미해결 질문.
3. 개체 페이지 갱신:
   - 처음 나온 개체 → `_templates/`로 새 페이지. `first_appears`와 첫 상태 행.
   - 기존 개체 → `## 상태 변화`에 이 장 행 추가 (변화가 있을 때만).
   - 고정 설정에 새 사실이 나오면 `(chNN)` 출처를 달아 추가.
   - 고정 설정과 원고가 충돌하면 원고를 따르고, 바뀐 이유가 불분명하면 `> ⚠️ 모순:` 블록 + 작가에게 보고.
4. `timeline.md`에 이 장의 주요 사건 행 추가.
5. `threads.md`: 새로 심은 복선 등록, 회수된 복선은 `회수 장`·`상태=paid`.
6. `terms.md`: 새 고유명사 등록, 원고에서 표기가 흔들리면 정본을 정하고 금지 변형 기록.
7. `_index.md`에 새 페이지 등록, `_overview.md`의 진행 상황 갱신.
8. `_log.md`에 `## [YYYY-MM-DD] ingest | chNN 제목` + 변경 파일 목록.

원칙: **원고에 실제로 쓰인 것만** 바이블에 넣는다. 작가의 계획이나 LLM의 추측은 `outline/`이나 `미해결 질문`으로 보낸다.
