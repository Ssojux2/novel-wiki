# 핵심 작법 원칙

howells/fiction의 Core Principles와 writer 에이전트의 감각, author-toolkit fiction-workshop의 창작 워크플로를 한국어 장편에 맞게 정리했다.

## 여섯 원칙

1. **이야기 = 인물 + 변화.** 플롯은 일어난 일이고, 이야기는 그 일이 인물에게 남긴 의미다. 장이 끝났을 때 누군가는 달라져 있어야 한다.
2. **장면 경제.** 모든 장면은 최소 두 가지 일을 한다 (플롯 전진 + 인물 드러내기, 세계 보여주기 + 긴장 높이기 …). 하나만 하면 합치거나 요약으로 돌린다.
3. **구체성이 보편성을 만든다.** "개" 대신 "다리 셋인 비글". "낡은 기지" 대신 "용접 자국 위에 다시 칠한 녹색 페인트".
4. **번 만큼 받는다 (Plant before harvest).** 큰 감정과 반전일수록 밑밥이 더 필요하다. 우연은 이야기를 시작할 수는 있어도 해결하지는 못한다. 모든 회수에는 심은 장이 있고, 모든 복선에는 회수가 있다 → `threads.md`.
5. **독자를 믿는다.** 감정을 설명하지 않는다. 함의, 침묵, 이미지로 맡긴다. 말하지 않은 것이 말한 것보다 무겁다.
6. **귀로 쓴다.** 소리 내 읽었을 때 걸리는 문장은 고친다. 오디오북에 맞게 화자 구분을 분명히 하고, 시각에만 의존하는 장치(표·도형)는 본문에 쓰지 않는다.

## 장면과 요약
- **장면**: 전환점, 높은 감정, 결정적 선택. 실시간으로 보여준다.
- **요약**: 이동, 반복 일과, 시간 경과. 한두 문장으로 건너뛴다.
- 규칙: 중요하면 보여준다. 중요하지 않으면 과감히 건너뛴다. "두 사람은 오래 이야기했다"처럼 장면을 요약으로 뭉개지 않는다. 쓰거나 생략하거나 둘 중 하나다.

## 시점과 시제
- 3인칭 제한: 친밀함과 유연성의 균형. 한 장면에 한 사람의 머리만 들어간다 (헤드 호핑 금지).
- 1인칭: 깊은 친밀함, 믿을 수 없는 화자 가능. 화자가 모르는 것은 쓸 수 없다.
- 과거형이 기본이다. 현재형은 긴박함을 주지만 장편 내내 쓰면 피로하다. 섞는다면 규칙을 정해 `CLAUDE.md`에 적는다.

## 한국어 문장 리듬
- 주어는 생략이 기본이다. "그는/그녀는"을 매 문장 쓰면 번역투가 된다.
- "~었다." 종결이 단조로우면 길이로 리듬을 만든다. 짧은 문장은 충격, 긴 문장은 축적과 호흡.
- 명사형 종결과 현재형 섞기는 효과를 계산했을 때만 쓴다.
- 대사 태그는 "말했다"를 기본으로 하되, 누가 말하는지 분명하면 아예 뺀다. 행동 비트("서윤이 장갑을 벗었다.")로 화자를 표시할 수 있다.

## 피할 것
- 감정 설명: "슬픔이 밀려왔다" → 커피가 손 안에서 식어 간다.
- 필터어: "문이 열리는 것이 보였다" → 문이 열렸다.
- 과잉 서술: 문장이 자리를 벌지 못하면 지운다.
- 편의: 문제를 푸는 우연, 플롯이 필요할 때 갑자기 변하는 인물.
- 요약문 같은 말: "자아를 찾는 여정", "복잡하게 얽힌 운명". 책 소개문에 나올 법한 말은 본문에 쓰지 않는다.
- 구조 표지: "장면 1", "Part A" 금지. 장면 구분은 `* * *`.

## 창작 사이클: 브레인스톰 → 선별 → 초고 → 다듬기
1. **장면 계획**: 무엇이 일어나야 하나, 누구 시점인가, 이 장의 감정선은, 독자가 끝에 무엇을 알고 느끼나.
2. **브레인스톰**: 비트 후보 5~15개 (도입 훅, 핵심 순간, 대사, 감각 디테일, 마무리).
3. **선별**: 작가가 남길 것, 합칠 것, 버릴 것을 고른다. 고른 이유를 들으면 다음 제안이 정확해진다.
4. **초고**: 고른 비트로 쓴다. 고칠 때는 부분 수정(Edit)을 쓰고 전체를 다시 출력하지 않는다.
5. **다듬기**: 피드백으로 반복한다. 거의 바뀌지 않는 패스가 3번 이어지면 "무엇을 덜어낼까?"를 묻는다.
